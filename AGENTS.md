# Instrucciones para agentes
- No modificar los nombres ni los tipos de los campos obligatorios del contrato del Laboratorio 2.
- No usar información del día objetivo ni fechas posteriores para entrenar o construir features.
- Escribir comentarios de código en inglés y pruebas con pytest.
- No guardar credenciales ni datos originales en Git o imágenes Docker.
- Antes de confirmar cambios, ejecutar pruebas, verificar Docker Compose y revisar el diff.
- Mantener la API operativa con el modelo cacheado cuando MLflow no responda.
